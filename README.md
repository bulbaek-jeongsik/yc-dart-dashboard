# 와이씨(232140) · OpenDART 재무분석 대시보드

DART 공식 공시 데이터를 직접 조회하여 와이씨(메모리 웨이퍼 테스트 장비 업체)의 재무제표를 정리하는 **서버 사이드 API + 브라우저 대시보드**입니다. API 키가 없을 때는 **가짜 수치나 샘플 데이터를 표시하지 않습니다**.

## 구현 기능

- 와이씨 DART 고유번호 **01109539** 고정, 종목코드 232140
- 2021–2025 연간 연결/별도 재무제표, 2026년 1분기·반기·3분기 공시 자동 조회
- 매출액, 매출총이익, 영업이익, 당기순이익, 영업현금흐름, 현금및현금성자산, 자산·부채·자본
- 영업이익률, 순이익률, 부채비율, 유동비율, 현금흐름 기반 간이 FCF
- 누적 보고된 분기 손익 및 현금흐름을 차감하여 실제 분기 실적으로 환산
- DART 원문 계정별 검색, DART 공시 원문 링크, 연간/분기 CSV, ChatGPT 분석용 JSON 내보내기
- 원본 API 키는 브라우저에 노출하지 않으며 Vercel 환경변수 또는 로컬 `.env`에서만 읽습니다

## 가장 빠른 설치: Vercel

1. 프로젝트 폴더를 새로운 GitHub 저장소에 올립니다. **`.env` 파일은 커밋하지 마세요.**
2. Vercel 대시보드에서 `Add New → Project → GitHub 저장소 선택`하여 배포합니다. 프레임워크는 `Other`/`No Framework`로 둡니다.
3. 프로젝트 `Settings → Environment Variables`에서 다음 환경변수를 설정합니다.
   - 이름: `DART_API_KEY`
   - 값: 본인 OpenDART에서 발급받은 40자리 인증키
   - 적용: `Production`, `Preview`, `Development` 중 필요한 범위
4. 환경변수를 추가한 뒤 **Redeploy**합니다. 대시보드를 열면 키를 브라우저에 입력하지 않고 자동 조회합니다.

인증키 신청: <https://opendart.fss.or.kr/> · 공식 전체 재무제표 API: <https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020>

## 로컬에서 실행하기

Node.js 20 이상 설치 후:

```bash
cp .env.example .env
# .env 안의 DART_API_KEY 값을 실제 키로 교체
npm run dev
# 브라우저에서 http://localhost:3000 방문
```

Windows PowerShell에서는 `Copy-Item .env.example .env`로 복사하세요. `.env`는 Git 추적에서 제외됩니다.

## 사용 및 계산 원칙

- **재무제표 기준:** 연결(CFS)/별도(OFS) 토글. 두 기준을 하나의 시계열로 혼합하지 않습니다.
- **재무제표 범위:** OpenDART `fnlttSinglAcntAll.json`에서 해당 계정의 `thstrm_amount`를 추출합니다. 일부 항목은 기업별 계정명 차이 때문에 공백일 수 있습니다.
- **연간:** 2021–2025년 해당 사업보고서 공시값 (2026년 11월 시점에서의 설정).
- **2026 분기:** Q1 = 1분기 누적, Q2 = 반기 누적 − 1분기 누적, Q3 = 3분기 누적 − 반기 누적. 중간 보고서가 없으면 뒤 분기 계산도 생략합니다.
- **재무상태표:** 특정 분기 말의 잔액을 그대로 표시하고 차감하지 않습니다.
- **영업이익률:** 영업이익 / 매출액 × 100.
- **부채비율:** 부채총계 / 자본총계 × 100.
- **유동비율:** 유동자산 / 유동부채 × 100.
- **간이 CAPEX:** 현금흐름표의 유형자산 및 무형자산 취득 금액의 절댓값 합계. 비현금 거래나 리스 등은 별도 반영하지 않습니다.
- **간이 FCF:** 영업활동현금흐름 − 간이 CAPEX. CAPEX 항목 미확인 시 계산하지 않습니다.
- **API 데이터 갱신:** 서버 메모리 캐시 15분. 새로고침은 화면 데이터 재요청이며 캐시가 살아 있으면 같은 공시를 보여줍니다.
- **DART 오류:** DART `013` (자료 없음)은 미공시 처리. 나머지 DART 오류는 별도 표시. 일부 연도 조회 실패 시 정상 연도만 표시하고 오류 목록을 상단에 노출합니다.

> 중요: 2026년 이후 시점에는 `lib/dart.js`의 `LAST_COMPLETED_YEAR`, `YEAR_START`, `REPORTS` 부분을 연도에 맞게 갱신해야 합니다. (현재 2026년 11월 분석을 위한 버전)
>
> 계정 매핑과 간이 FCF는 투자 판단이나 회계 감사 용도가 아닙니다. DART 원문과 교차검증하세요.

## ChatGPT로 직접 분석하는 방법

대시보드에서 **분석용 JSON**을 다운로드한 뒤 이 채팅에 업로드하고 다음처럼 요청하세요.

> 이 파일은 와이씨의 OpenDART 재무제표입니다. 2021~2025년 매출 성장과 영업이익률, 재고/매출채권/현금흐름 변화, 2026년 분기 실적을 분석하고 반도체 검사장비 산업의 투자 사이클과 연결해서 해석해줘. 금액은 억원으로 표시하고 모든 숫자의 공시 기간과 연결/별도 기준을 명시해줘.

현재 이 웹사이트는 ChatGPT 계정과 **자동 대화 연결**되지는 않습니다. JSON 업로드 방식이 안전하고 재현 가능하며, 추후 별도 인증·연동 기능을 붙일 수 있습니다.

## 전체 공시 아카이브 기능 (v2)

- **전체 공시 검색**: `#disclosures` 탭에서 와이씨 고유번호 01109539를 기준으로 1999년부터 현재까지 공시를 페이지별(최대 100건)로 탐색합니다. 정정공시도 목록에 포함하며, 정기·수시·발행·지분·감사·거래소·공정위 공시 등 OpenDART가 정의한 10개 유형의 필터를 지원합니다.
- **전체 목록 내보내기**: 화면의 **전체 목록 수집 → JSON/CSV**를 클릭하면 지정한 기간·유형의 목록 페이지를 순차 조회하고 메타데이터를 내려받습니다. 중단 시 `complete:false`로 기록합니다. 원문 전체가 포함된 다운로드가 아닙니다.
- **공시 원문 확인**: 보고서명을 클릭하면 OpenDART `document.xml`의 ZIP을 서버에서 읽고 XML/HTML/TXT 문서를 텍스트로 추출해 40,000자 단위로 표시합니다. 한 공시에 포함된 원문 구성 파일을 선택할 수 있습니다. DART 공식 원문 링크에서는 표·이미지·첨부파일을 온전하게 확인할 수 있습니다.
- **원문 ZIP 다운로드**: 최대 약 4MB의 ZIP은 사이트에서 직접 다운로드할 수 있습니다. Vercel 함수 응답 용량 제한으로 더 큰 ZIP은 DART 공식 원문 화면에서 확인하도록 안내합니다.
- **보안**: `DART_API_KEY`는 서버 환경변수에만 저장, 접수번호는 숫자 14자리로 제한하고 회사 공시 목록에서 발급한 서명 토큰으로 원문 조회를 검증, ZIP의 파일 유형·압축 해제 용량을 제한합니다. 브라우저로 API 키를 보내지 않습니다.
- **수집 범위 주의**: 이 아카이브는 **와이씨 고유번호로 DART 공시검색에 검색되는 자료를 전부 조회할 수 있는 인덱스**입니다. 모든 원문 내용을 서버에 사전 저장하거나 서로 다른 제출 법인 명의의 공시를 자동 연결하는 것은 아닙니다. DART가 제공하지 않는 첨부·표·이미지·XBRL 원본 및 정정 이력의 의미는 공식 원문으로 교차검증하세요.
- **기존 재무분석과 독립**: `api/data` 재무제표 조회에 오류가 있어도 공시 아카이브는 별도의 `api/disclosures` 조회를 시도합니다.

### API 엔드포인트

| URL | 역할 |
| --- | --- |
| `GET /api/disclosures?from=19990101&to=20261113&category=ALL&page=1` | 공시목록 100건씩 + 전체 건수/페이지 |
| `GET /api/document?receipt=...&token=목록서명&part=0&chunk=1` | 개별 공시 원문 텍스트, 40,000자씩 |
| `GET /api/document?receipt=...&token=목록서명&format=zip` | 4MB 이하 원문 ZIP 내려받기 |

공식 API 문서: [공시검색](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001) · [공시서류원본파일](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)
- **분석용 본문 TXT**: 공시 원문 미리보기에서 원문 구성 파일을 선택하고 `선택 파일 전체 TXT`를 클릭하면 40,000자 조각을 이어서 내려받습니다. 기업분석 보고서에 사용할 때는 원문 접수번호·일자도 함께 기록하세요.
